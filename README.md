# What is the difference between remote and local repositories?
# A local repository lives on your own computer. You edit, stage, and commit there, and it works offline. But only you can see it. A remote repository lives on a server it is the shared copy that others can clone it and contribute to it, and it also works as a backup. The two do not sync on their own. But your commits stay local until you git push them. Changes on the remote reach you only when you git pull or git fetch.
